### 环境准备

此AI需在Mumu模拟器环境下进行，下载网址：https://mumu.163.com/

游戏本体文件在项目根目录中，拖入Mumu模拟器即可自动安装

游戏语言默认为繁体中文，需先设置为简体中文后重启才可以识别文字。

目前程序只支持第一关代理

启动AI代理前，需先手动通关第一关并领取奖励后放弃这局游戏，重开一局领取涅奥的奖励，待教程提示都触发后才可回到主界面启动AI。

### 启动步骤

1.打开Mumu模拟器，打开杀戮尖塔游戏，进入主菜单界面（需显示为开始游戏，若为继续游戏则先放弃这局游戏）

2.双击MaaPiCli.exe，弹出命令行

![1735811989060](C:\Users\76279\AppData\Roaming\Typora\typora-user-images\1735811989060.png)

3.选择Switch controller->Auto detect，待识别出Mumu模拟器后选择Mumu模拟器，之后就可以选择Run tasks运行AI代理自动进行游戏了。
